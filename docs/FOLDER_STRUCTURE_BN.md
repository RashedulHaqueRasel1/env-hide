# env-hide: Folder structure

```text
src/
├── index.ts                 # Public programmatic API
├── cli.ts                   # Executable entry point and error boundary
├── core/
│   ├── crypto.ts            # Argon2id + AES-256-GCM and secret-file format
│   └── errors.ts            # Safe, user-facing error types
├── cli/
│   ├── index.ts             # Command routing and CLI workflows
│   └── password.ts          # Secure interactive password prompt
├── config/
│   └── env-files.ts         # Supported filenames and secret-file mapping
├── infrastructure/
│   └── filesystem.ts        # .gitignore and atomic filesystem operations
├── scripts/
│   └── postinstall.ts       # Consumer project setup after npm install
└── __tests__/
    └── crypto.test.ts       # Encryption/decryption tests
```

## Layer rules

- `core/` is independent business and security logic; it must not depend on CLI code.
- `config/` is the single source of truth for supported environment-file names.
- `infrastructure/` contains reusable platform helpers such as filesystem access.
- `cli/` coordinates commands and may import from `core/`, `config/`, and `infrastructure/`.
- `index.ts` stays deliberately small: it exports the supported library API only.
- Tests mirror the feature they validate and live separately from production files.

Compiled output follows the same layout under `dist/` and is generated by `npm run build`.
`npm run build` আগে পুরোনো `dist/` clean করে এবং production package-এ test output রাখে না।
